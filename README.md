# Médias Nuvio

225 images et animations WebP pour une collection personnelle Nuvio.

Les médias sont servis individuellement depuis le dossier `assets/`. Les animations se déclenchent à la sélection des cartes dans Nuvio.

Ce dépôt contient uniquement les médias. La configuration des collections, les sources de catalogues et les données de compte sont conservées séparément.

Les noms de marques et leurs logos appartiennent à leurs propriétaires respectifs.
